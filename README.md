# Путеводитель по Шымкенту

Добро пожаловать на наш сайт-путеводитель по городу Шымкент! Этот проект был создан командой 12H, чтобы помочь жителям и гостям города лучше узнать его достопримечательности, культуру и уникальные места.

## О проекте

Наш путеводитель предоставляет информацию о самых нужных местах Шымкента, включая Аптеки, ТРЦ, парки, рестораны и многое другое. Мы стремимся сделать ваш визит в Шымкент незабываемым и насыщенным.

## Основные функции

- **Подробная информация**: Легко находите интересующие вас места на карте города.
- **Категории**: Просматривайте достопримечательности по категориям (история, культура, еда и т.д.).
- **Отзывы и рейтинги**: Читайте отзывы других пользователей и оставляйте свои.
- **Маршруты**: Создавайте свои маршруты и делитесь ими с друзьями.

## Вклад

Мы приветствуем вклад сообщества! Если у вас есть идеи по улучшению нашего путеводителя или вы нашли ошибку, пожалуйста, создайте issue или отправьте pull request.
